
# Gen-AI Powered UI/UX Design Platform 🎨🤖

A voice-driven Gen-AI-powered Streamlit application that listens to user ideas in Indian languages and auto-generates rich, animated HTML UI designs using Gemini, NVIDIA NeMo, and Sarvam AI APIs.

---

## 🚀 Features

- 🎤 Voice Input (Multiple Indian Languages)
- 🧠 Gemini LLM for HTML UI generation
- 📊 NVIDIA NeMo for semantic matching via embeddings
- 🔊 Sarvam AI for speech-to-text and text-to-speech
- 🌐 Auto-generated rich HTML web pages with Tailwind CSS
- 🔎 Multilingual support with real-time response

## 🧰 Prerequisites

Ensure Python 3.8+ is installed.

### 🔌 Required Python Libraries
Install them using pip:

```bash
pip install streamlit openai python-dotenv requests singlestoredb pydub
```

Also, install `ffmpeg` (required by `pydub`):
- Windows: [Download ffmpeg](https://ffmpeg.org/download.html) and add to PATH
- Ubuntu: `sudo apt install ffmpeg`

---

## 🔐 API Keys (Required)

Create a `.env` file in the project root directory and include the following:

```env
GEMINI_API_KEY=your_google_gemini_api_key
SARVAM_API_KEY=your_sarvam_ai_api_key
NVIDIA_API_KEY=your_nvidia_nemo_api_key
```

---

## 🏃‍♂️ How to Run

1. Open a terminal in the project directory.
2. Run the Streamlit app:

```bash
streamlit run Works.py
```

3. The app will open in your browser (usually at `http://localhost:8501`).

## 📝 How It Works

1. You **record a voice input** describing the UI you want.
2. The app:
   - Transcribes it (Sarvam Speech-to-Text)
   - Matches it with existing examples (NVIDIA Embeddings)
   - Generates a full HTML website using Gemini (via OpenAI-style API)
   - Reads out the reply (Sarvam Text-to-Speech)
3. The result is saved in `generated_app.html` and opened in the browser.
